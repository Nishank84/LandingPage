GAME UP - BRAND COMPONENTS (SVG)
Every component from "Game Up - Brand Guidelines.html" as its own SVG, transparent background.

FOLDERS
  logos/                          symbol, horizontal/stacked lockups, wordmark, app icon (all colour variants)
  icons/                          every icon, one file per icon + colour (24-unit grid, 96 px default)
  illustrations-and-backgrounds/  launch-streak art and hero background art
  cards/                          all cards (values, personas, tone, colour, applications, downloads ...)
  icon-tiles/                     the rounded icon badges / circles
  chips-and-buttons/              pills, tags, buttons, status badges
  section-layouts/                nav bar, cover, page heroes, CTA and footer bands
  text-styles/                    one file per distinct type style (font, size, weight, colour, gradient)
  text-styles/eyebrow-labels/     the small line + caps label headers
  index.html                      open in a browser to preview everything (toggle light/navy background)

FONTS - install before converting to PNG
  Unbounded (600/700/800/900) and Plus Jakarta Sans (400-700), free on Google Fonts.
  Text is kept as live <text>, so the SVG picks them up if installed. Logos are already outlined paths.

TIPS
  * Card/tile files include transparent padding so soft shadows are not clipped.
  * White/light artwork (reversed logos, text on navy) looks blank on white - use the navy toggle in index.html.
  * Export PNGs at 2x-4x for sharp results.
